# Changelog

Histórico completo e detalhado em [`docs/log.md`](docs/log.md) (formato OKF). Resumo das versões recentes abaixo.

- Licença MIT (`LICENSE`), autenticação no portal web, reconexão automática de Wi-Fi, indicador de dado desatualizado, dependências git fixadas, CI de build, infraestrutura de comunidade (`CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, templates), limpeza de código morto.
